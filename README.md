# Polarization
Polarization in the rotating frame - simulation and analysis

## Description
This code is a result of a work under the supervision of Prof. Ben Z. Steinberg. 
In here are TM simulations of polarizability theory in a rotating frame of refernece, based on the Green function as derived here: https://www.eng.tau.ac.il/~steinber/papers_ps/RotatingG_PRE_SteinbergShamirBoag.pdf

The repo can be separated into 3 parts:
1. Generic functions and simulation parameters (Green functions, Calculation methods, constants)
2. Polarizability simulation of a small dielectric cylinder in TM as fucntion of (\Omega, \Rho)
3. Simulation of multiple scatterers under rotation (comparing 3 methods: MoM, Fillaments, scalar polarizability).

This simulation supports the analytic calculations found in (Paper).
